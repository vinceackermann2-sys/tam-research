## Question
Can the **actual original screenshot-inspired hybrid** (causal local attention + gated recurrence + top-1 sparse MoE + refinement/world prediction) infer hidden episodic action effects and **choose better actions toward goals** than both a matched-parameter dense causal Transformer and classical online system identification? Earlier SI evaluations used only next-step MSE; they did not establish useful planning or transferable world dynamics.

## Locked source / environment
`scripts/si_original_planning_transfer_v3.py` imports UNCHANGED `tam_research.si_original_hybrid_v0.OriginalSIHybrid`, `TransformerControl`, `SIConfig` and `prediction_loss` from original branch. Nominal params: **64,614** vs **64,637** (difference 0.036%). The hybrid retains reference implementations of 3 blocks, recurrence, experts, and refinement; episodic memory store is **NOT** fused into forward pass and modality IDs are **not** real text/audio/image training. Do not claim full SI or general intelligence.

Each episode generates secret 3x3 state-transition matrix and 4x3 action-effect matrix, with four possible actions and observed state trajectory length20. Three **training** families rotate predictably by optimizer step: `direct` current-action transition, `delayed` current plus previous action effects, and `switch` independent transition/effects halfway through sequence. Fourth `nonlinear` family has withheld multiplicative state couplings, **never appears during training**. Dynamics and action-effect matrices sampled fresh per episode. The model sees only causal sequence `(state_t, action_t)` and predicts `state_(t+1)`; private matrices or future states never passed in.

At held-out evaluation, each example asks for the best next action toward a noisy goal created from one actually executable action outcome. The ground-truth simulator evaluates ALL four counterfactual next states. The learned agents must predict the four outcomes via **four query actions with IDENTICAL observed prefix**, select the action minimizing predicted goal-distance, and are scored against the true optimum. The true transition matrices remain EVALUATOR ONLY.

**Strong controls:** uniformly random actions; parameter-free ridge regression of completed transition histories (all 19 completed samples, or most recent 6) with current action, previous action, current state and intercept. No target or query transition enters classical fitting. Compare held-out next-state MSE on the four counterfactual query actions, true action-selection **accuracy** (% matching oracle), mean **regret** (achieved squared goal error minus oracle minimum, lower better), true realized cost, CPU training time and param count.
