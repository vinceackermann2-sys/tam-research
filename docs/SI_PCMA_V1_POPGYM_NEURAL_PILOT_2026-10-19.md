## Why this milestone matters
Earlier PR #1516 showed from the externally authored ICLR 2023 POPGym tasks that deterministic cheap public memory achieves **+1.0 maximum return**, while a current-only agent scored negative on three tasks, at 8 common engineering episodes each. That is a genuine task-memory positive control, but **no neural model was actually evaluated**.

This PR performs a first, intentionally **limited** trial of the actual original hybrid versus an original-config Transformer on those published tasks, using **one identical public data encoder, one identical task-conditioned classifier, and the same supervised training budget**. The original hybrid/Transformer backbone source itself is not modified. This is not PCMA-v1's original causal factual probe task; we are checking only whether the source backbones can *learn basic public sequence memory* rather than assuming that passing infrastructure tests implies intelligence.

## Frozen developer training recipe (PR-specific, CPU only)
- Unmodified external dependency: `popgym==1.0.7` (installed only in this PR's CI).
- Task set: `RepeatFirstEasy`, `RepeatPreviousEasy(k=4)`, `CountRecallEasy`. This selected easy set was justified and checked for public-memory dependence in parent PR #1516; it is not a protected architecture competition.
- **Development-training IDs**: exactly integers **101..112**, 12 episodes/task (36 total); **disjoint development-validation IDs**: **201..208**, 8 episodes/task (24 total). No heldout task or scientific-run seed IDs. No hyperparameter or task changes after inspecting the resulting scores.
- Public observation sequence: exactly **51 observations** per episode. Normalized suit (or dealt/queried color), and environment task identifier only, in three numerical channels. All four historic action input channels are **zero** for every token so no earlier *teacher-selected* action can leak the missing memory label. The unmodified backbone's original modality embedding encodes only known task ID. Both architectures receive bit-identical input and use the same **3→27 output readout**, masking invalid actions for suit tasks.
- Supervision: **deterministic exact public-memory algorithm** derived only from the observed card sequence. Its targets are NOT hidden-state labels, world-oracle annotations or observed environment rewards. This is behavior cloning/imitation, not online factual reinforcement learning. The first three `RepeatPreviousEasy` positions get zero loss weight because that task awards no reward until its four-observation history exists.
- Same initialization fixture 70631, same `AdamW(lr=0.002, weight_decay=0)`, same gradient norm clipping 1, same **48 training updates** with one episode from EACH task per update (three task-weighted training trajectories per step), covering all 12 training IDs four times. `torch.set_num_threads(2)` in the CI pilot; no GPU / Modal / Colab. This is a smoke/falsification budget, not enough to certify mature training.
- At validation, each backbone produces a strictly causally masked prediction for each of 51 time steps. The prefix-invariance test verifies that early predictions are not affected by later input tokens. The resulting 51 chosen actions are then **actually executed** on a fresh instance of the same POPGym environment with the same development ID; every public observation must exactly match the action-independent recorded trajectory or the run aborts. Rewards come from the external environment's `step()`, NOT offline expert accuracy or invented counterfactuals. Task returns and public-expert action accuracy are reported separately.
- Baseline ceiling: cheap exact public-memory control gets normalized **+1.0** per published task, as established in PR #1516; no architecture may claim to beat it on these tasks. Report `may_claim_hybrid_advantage=false` and `active_training_flops_matched=false` independent of the observed returns.

## Why this is NOT a fair scientific PCMA comparison
1. **No learned PCMA state** in this pilot: it uses only the unchanged original hybrid and Transformer core plus shared readout, not the successor's external persistent factual memory and bounded rank-2 online adapter. It is a backbone memory *smoke test*, not a causal PCMA test or probe value study.
2. **Unequal active FLOPs**: one training update on a hybrid recurrent/MoE/refinement network does not cost the same as one Transformer update. The profiler is partial. Interpret any performance difference descriptively; no claims of matched-compute advantage.
3. **Three-dimensional world-head bottleneck**: both original networks predict 3 numerical dimensions, then a shared adapter projects to 27 action logits. This is faithful to the original source without modifying it, but is not guaranteed to be the best readout architecture for either model. Cannot treat low return as an impossibility of learning.
4. **Imitation of a hand-coded public policy**: labels require a task-specific teacher (allowed for a nonconfirmatory memory acquisition sanity check). That does not establish online self-directed causal world-model learning or autonomous SI.
5. **Small public tasks**, solved perfectly by cheap classical memories. They cannot show superintelligence or novel architectural efficiency, and may be too easy for meaningful comparisons. Even an excellent score here would mean memory capability, not a special PCMA advantage.
6. **Developer episode validation is not sealed heldout**: the published task source, model details, episode IDs, training plan, and CI output are public, and all test IDs are developer fixtures. No preregistered effect/uncertainty thresholds, full global attempt ledger, independent challenge authority, or paid-compute approval exists.

## GO/NO-GO relevance and next boundary
If the two original backbones cannot learn these basic public memories even from transparent demonstrations in 48 bounded updates, treat it as a **development training insufficiency signal**, not a scientific architecture failure. Do not relabel a negative result as success. If one is better, report both returns, the cheap optimal classical ceiling, training cost mismatch, and the absence of the external PCMA mechanism. **DO NOT scale or declare a breakthrough from this alone.**

The meaningful future experiment would freeze a harder independently authored POPGym memory/control family, nonprivileged **causal online learning**, PCMA memory and adaptation attached identically to hybrid and Transformer, sufficient training examples, complete forward/backward active FLOP accounting, strong finite-state and planning controls, world-cluster uncertainty, independent heldout generators/seeds and hard stop thresholds.
