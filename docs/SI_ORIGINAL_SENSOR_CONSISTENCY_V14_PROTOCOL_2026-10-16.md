## Identifiability motivation
V13's 2-sensor fallback recognizes some enumerated target-sensor flips, but not corrupted *trusted reference* readings, and its selector was no better than a shuffled selector. With two disagreeing sensors the faulty channel can be unidentifiable; independently measured calibration information can help identify a faulty reference, but the third channel also can fail. v14 is a **hand-coded sensor redundancy experiment**, not autonomous world-model discovery or full SI.

Simulator additionally creates **third independent observed calibration** `anchor_cal[i] = theta_cal[i]*1.8 + N(0,1)` using separately seeded noise. Hidden theta is used by environment to GENERATE readings only, never in detector/neural inference. Neural raw/bel models are unchanged and DO NOT see the anchor directly. Consistency score `S=mean_i(y_cal[i]*anchor_cal[i]/(mu_ref*1.8))`. A possible reference fault is flagged iff **S<0.50**. For repair, use physically observed `y_cal_repaired=anchor_cal*(mu_ref/1.8)` in the neural input; this changes the noise law, a documented limitation. Charge a fixed synthetic information fee **0.025 reward per episode** for ANY anchor-based action, even when not substituted. This is not electricity/hardware FLOP equivalence.

Control modes, all scored on same underlying episodes: `raw`, `belief`, previous `v13_fallback` (no third channel/fee); `always_anchor_belief` (replace reference on every episode, pay fee); `consistency_repair` (replace reference only when flagged, pay fee); `shuffled_repair` (same repair fraction **within evaluation family** assigned randomly, pay fee; negative control); `repair_plus_v13_fallback` (both selectors, pay fee). All models use canonical identical v12 logged-outcome contextual critic: 180 actor updates+200 chosen-arm critic updates, batch96, CPU 2 threads, same seed training stationary and one target flip. OriginalSIHybrid 64,614 vs matched Transformer 64,637 parameters per model, smaller unmatched GRU 10,283. The v13/v14 fallback involves **two entire networks**, so no equal FLOPs or compute efficiency claim. Score actual fee-adjusted net reward, final accuracy, paid probe fraction, error/fallback detection rates, wall-clock training and per-seed differences.

Held-out families (8): base stationary; familiar one_flip; unseen double_flip; **reference_drift** (reference sign reversed last3); **reference_drift_early** (reference sign reversed first3); **reference_dropout** (reference high-variance corrupted last3); **anchor_drift** (the new third sensor sign reversed last3; unsupported, essential negative control); weak_calibration.
