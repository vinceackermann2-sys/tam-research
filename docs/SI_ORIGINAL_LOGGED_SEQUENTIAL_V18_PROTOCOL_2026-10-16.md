**Training signals and causal ordering, frozen**:
1. **Action predictor (160 AdamW steps):** randomly buy first low or high and intentionally buy both probes on logged training interventions, execute random final binary action, observe correctness from the simulator, reconstruct true binary answer using *executed action + observed correctness*, train final binary outcome head with BCE on actual observations after first and after second. This is supervised binary feedback, NOT unsupervised learning.
2. Freeze backbone/final-action head. **Two-stage logged Q estimates (240 head-only AdamW steps)** from freshly randomized worlds, same across model architectures: first-stage logging uniformly chooses `stop/low/high`; stopped cases observe actual correctness of a random executed action, train ONLY observed `Q0[stop]`. Bought-first cases independently buy or skip remaining second with a fair coin; execute **the frozen action predictor** based on observations actually purchased, observe correctness and deduct actual second cost, train ONLY the selected `Q1[skip|buy]`. Learn selected first-action `Q0[low|high]` with one-step **detached bootstrapped max Q1 minus actual first cost**, conditional on the observed first probe. The bootstrap contains the model's *estimated* value of an unchosen action, NOT a synthetic unobserved reward target or Bayes policy. This can cause overestimation and self-confirming bias; report failures honestly. A logged actor action may be randomized; the optimizer never sees latent truth as a direct label or future unpurchased probe in the policy.
3. At inference first action = argmax Q0; after first observed probe, buy the second iff Q1[buy] > Q1[skip]; final action = sign of frozen classifier output on purchased observations; if no probe, default +1, yielding exactly 50% over counterfactual twins. Exact known-model Bayes is used solely for EVALUATION, not as v18 teacher.
