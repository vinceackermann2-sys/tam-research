## Prior evidence and why this task changes the question
- Original source-attested SI hybrid+fast-memory v6 lost to matched Transformer+memory and classical system identification on unseen nonlinear closed-loop planning.
- v7 task validation found a supervised GRU copied a known Gaussian Bayes sensor-purchase strategy, but failed to adapt when the observation model was corrupted. That v7 per-episode task revealed only a single unreliable cue and did **not** give the agent evidence to identify changed sensor reliability.
- v8 deliberately provides **six independent calibration trials** with a noisy target sensor and an independently noisy but trusted reference sensor before a new hidden-mode query, so the agent can infer each episode's *hidden sensor polarity*. The hidden polarity z is fixed during an episode, with prior P(z=-1)=0.5 in training. Each calibration mode theta_i is an independent unobserved ±1 bit. Target observations x_i~N(z theta_i mu_cal,1), reference observations y_i~N(theta_i mu_ref,1); both x_i and y_i arrive before the query. New query theta is independent; observe x_query~N(z theta mu0,1), then optionally pay cost c for trusted y_probe~N(theta mu_probe,1), then choose theta. Reward = 1[chosen theta==true theta] - c*1[buy].
- Observed strengths and costs, all calibration cues and purchased probe ONLY, are in model input; hidden theta, z, unpurchased probe and simulator parameters are excluded from inference. No latent future leak. This is a small synthetic active-sensing problem, NOT broad-world SI or multi-step POMDP control.

## Main and strong baseline comparisons
Canonical, **unchanged 298-line full original module** `tam_research/si_original_hybrid_v0.py` Git blob `575c17dc2f39a29d930d82179aa0c96dcbdc7d0f`, locally byte-verified. Models **OriginalSIHybrid 64,614 params** and **TransformerControl 64,637 params** keep the same causal 3-layer/width40 backbone, token representation, output head use and training streams; original's recurrence, local attention, sparse MoE, optional refinement all operate, but old external EpisodicMemory is **NOT integrated** and v4 fast-weight delta-rule is **NOT attached** (this experiment tests ordinary within-context learning/belief representation). Both are trained from synthetic targets for (a) optimal probe-purchase label under the analytic training-world Bayesian controller, (b) hidden query theta final action, and (c) auxiliary hidden z polarity label. The auxiliary z label is available only in *offline synthetic supervised training*, NEVER during evaluation/inference; do not call it self-supervised world discovery. A small independent GRU 10,283 params receives identical observations and supervision as a third neural control; parameter/compute unmatched, reported transparently.

Reference methods: exact conjugate/binary Bayesian posterior on z via marginalizing hidden calibration modes; Bayes optimal value-of-information probe decision given posterior theta; no-calibration Bayesian prior 50/50; never-probe and always-probe policies with same posterior. Bayes is a **known-model upper reference**, not a fair learned competitor for unknown models. Under OOD shifted z prior (P(z=-1)=0.8) Bayes intentionally retains the *training* prior 0.5, so it is slightly misspecified; report this.

## Frozen data and computational budget
- Six calibration trials per episode, 7 causal input channels / token (three original observation dims and four action-feature dims); two forward passes: first for probe purchase from calibration+query, second for final mode action after optional purchased probe. Shared 3-output prediction head indexes (0=probe logit,1=action logit,2=auxiliary sensor-polarity logit), no future token feedback to earlier query.
- Training `base` only: z balanced, mu0 uniform [0.35,1.4], mu_ref uniform [1.55,1.75], mu_probe uniform [0.9,2.15], cost uniform [0.03,0.30]. Holdout families: `inverted_prior` z flips with p=.8, `noisy_reference` mu_ref [0.6,1.15], `weak_calibration` mu_cal=.38*mu0 (known factor); no held-out family used in training.
- **Fresh confirmation seeds 100211,100212,100213**, no previous uses. Each one-time CPU attempt, no automatic retry, 240 AdamW steps/model × batch64 × 2 threads, LR=.001, wd=.01, gradient clip1. No knowledge-state continuation across minibatches. Deterministic training sample seed `seed*1000000+step`; matched random probe-mask generator `seed*1000000+step+987001` independent of initialization draws for all 3 controls. Evaluation 8192 worlds/family/seed at `seed*1000000+80000+127*family_index`; same episodes for all controls. Report mean reward, final accuracy, probe rate, sensor-polarity Brier score, polarity accuracy, model params, CPU training times, per-seed and overall. No statistical generality beyond this synthetic family.
- Implementation verified locally BEFORE freeze: source `scripts/si_original_belief_transfer_v8.py` blob `233dff4d660da142fbb57a91cd06b0c4ec17a0d0`, SHA256 `b3d0350bfbde917c8ce61060a8e22b4d9b680dbe1196ba97594859faf9ee413d`; tests `tests/test_si_original_belief_transfer_v8.py` blob `a72624c17f6dc9eb09b9b3695498c1a7cf740551`, five local tests passed. **Exploratory** seed100001 (4-step smoke), seed100101 (180 steps/batch64/2048 eval) only, not used for confirmation. They showed the hybrid lagged the Transformer in normal reward (about .768 vs .812), so no post-hoc hyperparameter tuning was performed. This selection is not scientific replication; heldout seeds assess the frozen method.
