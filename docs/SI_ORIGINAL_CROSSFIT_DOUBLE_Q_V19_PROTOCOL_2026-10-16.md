## Source-verified models, logging and independent-critic control

Pair unchanged **v18 same-Q** model vs **v19 crossfit double-Q** for each of the canonical **OriginalSIHybrid (64,638 params with task heads)**, nominally matched **TransformerControl (64,661)**, and smaller unmatched **GRU (10,307)**. The crossfit model adds **one 3-to-2 linear Q head = 8 parameters** to each, no changes to original recurrence, local attention, sparse MoE, refiner or causal observation tokens. Persistent memory and real multimodality are dormant.

**The 160 actor/backbone AdamW steps are LITERALLY the unchanged v18 trainer invoked with zero critic steps**; the extra critic is instantiated AFTER actor training. For identical seeds, both conditions receive byte-identical actor/backbone weights and the same world/feedback generation; tested in unit tests. Training worlds are the same paired opposite-label v17 base environments. Actor learns final binary outcome from *actually purchased* probes, executed action + correctness feedback; no hidden answer directly enters optimizer and no future unbought readings are consumed.

**Critic 240 head-only AdamW steps**, batch96, LR .003, WD0, same deterministic v18 logged first choice (uniform stop/cheap/strong), same random actually logged second buy/skip, same observed correctness/actual costs. For the purchased-first subset only: critic A is regressed on even-index logged trajectories, critic B on odd-index logged trajectories; BOTH regress only the *actually taken second arm* and NEVER a synthesized unpurchased reward. Critic A chooses the max second action while critic B evaluates its value in the detached first-stage bootstrap, net first-probe cost. First-stage Q0[stop] is trained on randomly executed stop-action correctness as in v18. **Test-time second value = mean(A,B)**; stage0 = Q0 argmax. This has only half the Q1 samples per critic vs single-Q, and extra params/compute; it is not an equal-effective-sample/FLOP comparison and its critics share a frozen actor representation (not independent complete networks). Double-Q is a known technique, not a newly invented SI mechanism.

Causal tests require no hidden answer/private world label/unpurchased probe access before purchasing, actor-source equality and observed-arm-only gradients. An independent randomized-logged second-stage arm is evaluated with **heldout mean squared prediction error** on actual net correctness-minus-cost; this is a model-selection diagnostic, NOT oracle target for training.
