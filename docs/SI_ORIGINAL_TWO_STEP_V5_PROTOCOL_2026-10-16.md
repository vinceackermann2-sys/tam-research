# Original SI: two-action planning gate v5 — preregistered CPU engineering test
Frozen 2026-10-16; isolated branch `experiment/si-original-two-step-planning-v5-20261016`, stacked on fast-memory v4 PR #1476 -> original hybrid PR #1459. Do not merge main or launch GPU; no automation. No EHW experiment is substituted.

## Question and simulator
Does the **actual original recurrent/attention/MoE backbone with the same learned fast episodic memory** outperform an equally equipped Transformer at *planning two actions into an unfamiliar world*, rather than using only a one-step planning proxy? Are they competitive with a strong classical system-identification controller?

Two trained models: `FastEpisodicMemory(OriginalSIHybrid(SIConfig()))` (**65,527 nominal parameters**) and `FastEpisodicMemory(TransformerControl(SIConfig()))` (**65,550**). Same causal rank16 online update from *completed past state transitions*, same training seeds/data/hyperparameters. They predict outcomes of each 2-step action pair (16 pairs), from an observed 20-timestep history. At query step20 the new observation is a model-imagined **first-step prediction**, never the true future. Action pair costs are assessed by a simulator using hidden matrices accessible **only to evaluator**, including feedback of action1 into action2. Goal is constructed from a randomly sampled executable two-step plan plus fixed Gaussian noise. Primary is actual **oracle-pair accuracy** (tie-aware comparison requires reporting regret too) and **two-action regret** on the held-out nonlinear family. Additionally score three trained families: direct, delayed, switch.

Baselines: **ridge all-history** and **ridge last-six**, each fitted on observed completed transitions only and rolled forward two steps without refitting on imagined targets; random uniform sequence of 16 pairs. This is an **open-loop** two-step action-pair planning task, NOT closed-loop replanning, partial observability, language intelligence, persistent continual memory, or deployment evidence. Same observational history and candidate actions for every planner. Single source files: `scripts/si_original_two_step_v5.py`, `tests/test_si_original_two_step_v5.py`.
