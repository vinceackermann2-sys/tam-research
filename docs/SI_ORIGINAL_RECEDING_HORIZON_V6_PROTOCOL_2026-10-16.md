## Counterfactual task and paired alternatives

Fresh independent hidden-world episodes, each with states x0..x19 and past actions a0..a18, unknown per-episode transition matrices and action effects. Four families: `direct`, `delayed`, `switch` (training) and unseen `nonlinear` (held out from training). Goal sampled from an actually achievable two-step final state plus Gaussian observation noise.

Each planner FIRST chooses one of 16 pairs (a19, a20) based on **its own** causal two-step imagined outcomes. Measure **open-loop** realized regret for implementing the entire chosen pair. The environment then executes ONLY its first proposed action a19 and reveals the **TRUE** resulting x20. The same planner sees x20 and the completed a19 transition, recomputes its fast episodic memory or retrains ridge from observed history and chooses a new second action a20. **Closed-loop** regret compares this changed second action against the global 16-action **oracle** final-state cost. Compare each planner open vs closed on the exact same worlds, goals and first action, so feedback effect is paired.

No model receives unknown transition matrices, true x21, true oracle action, or actual future state for any unexecuted action. Only the evaluator uses hidden law to execute chosen actions and score regret. This is **two-step replanning with full state observation**, not partial observability, Bayesian uncertainty, long-horizon or autonomous SI.

Four planner controls: original full hybrid+identical rank-16 fast memory (65,527 parameters); dense Transformer+identical fast memory (65,550); online linear ridge `all history`; and `last six completed transitions`. Plus random action-pair baseline (open-loop). All use the same worlds, simulated intervention goal, and input histories. Receding-horizon second-stage inference includes real x20 (not the model's imagined x20), and fast memory updates from this newly *completed* a19 transition. The single original full hybrid model, memory and previous harness remain **unchanged**. Original same-memory Transformer is a mandatory control; any gain from receiving true feedback is not uniquely attributable to the SI stack. Report 2-step accuracy and regret, change frequency of second action, CPU train and evaluation seconds, params and memory learning rate.
