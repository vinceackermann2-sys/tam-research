## Narrow falsifiable hypothesis
V19's disjoint-arm double-Q improved average second-stage Q1 observed-arm MSE, but hybrid and Transformer repeatedly made irrational *first-stage* decisions, buying the cheapest first even if the strong one was deeply discounted, and buying a second almost always or never depending on seed. V19 first action Q0 was trained from a **bootstrap** that selected Q1-A's max action and valued it with Q1-B after observing the first purchased probe. V20 tests whether fitting Q0 directly from REAL logged **complete-trajectory rewards** improves first-probe choice and realized cost-adjusted reward.

### Matched mechanism and resource controls
Train each original v19 disjoint-double-Q model **ONCE** per seed: original hybrid (canonical 64,614-param attention/gated-recurrence/top-1 MoE/refiner backbone), matched Transformer (64,637 backbone), and smaller GRU (10,283 backbone), each with unchanged v18 24 task-head params plus 8 v19 second-Q-head params. Then clone identical frozen weights into THREE policies: `frozen_v19` (no further training), `extra_bootstrap` (160 additional Q0-only AdamW updates on fresh logged worlds, **same v19 disjoint-Q bootstrap target**), and `direct_logged_return` (the SAME 160 Q0-only updates on the SAME randomized worlds, but target **ACTUALLY OBSERVED FULL RETURN**). All parameters except the first-stage three-output Q0 linear head stay frozen and byte-identical; no changes to the actual canonical original model, no teacher policy labels. This design controls extra optimizer updates and source/initialization, but the fraction of usable logged trajectories differs between targets and effective sample size/active compute are NOT identical.

For each fresh training episode, logging independently selects first `stop/low/high` uniformly and then (if first purchased) buys/skips the remaining second sensor independently at probability 0.5. If stopped, execute a random final binary choice and observe correctness: that *actual* reward is a Q0[stop] label. If first purchased, **before seeing the unpurchased second reading or outcome**, use frozen Q1-A/B average to determine the deployed second decision. Keep only logs whose independently randomized second action AGREES with deployed Q1: the logged chance of agreement is 0.5, independent of latent outcome given observed first. Execute the already-frozen final classifier with only ACTUALLY purchased probe(s), observe correctness and subtract first and (if purchased) second cost. Regress Q0 for **only the logged first action** against that actual net reward. No unobserved counterfactual reward, hidden truth, private world kind, unpurchased future probe or Bayes purchase label enters optimizer. **This estimates the value of the *frozen Q1-deployed continuation*, not of an optimal unknown second policy**. The policy-agreement filter is an off-policy evaluation design using randomized logging; sample loss/variance and support must be reported. The model class is limited to the same small linear Q0 head.

`extra_bootstrap` starts from IDENTICAL frozen v19 model, uses the same first-arm logged worlds and 160 Q0-only steps but computes the old Q1-A-select/Q1-B-evaluate target on first-bought episodes (all first-bought eligible), and actual random correctness on stop episodes. Exact PyTorch two CPU threads, identical LR=.003, weight decay=0 and optimizer/memory selection. Do not interpret a direct-vs-bootstrap gain as a pure label intervention independent of data-coverage differences.
