## Research hypothesis
The previous source-matched original SI hybrid v8 learned episodic hidden sensor polarity when **directly trained with synthetic latent-polarity z labels, true hidden query-mode labels, and analytic Bayes probe/purchase decision labels**. V8 normal reward hybrid 0.795203, matched Transformer 0.815619, smaller GRU 0.829782, known-model Bayes 0.850919; unchanged hybrid lost. These explicit labels made environment identification relatively easy and did not demonstrate autonomous inference.

V9 tests a stricter but still simple form of **learned observation-model inference and active sensing from rewards**:
1. Each example supplies six paired noisy target/reference **observable** calibration cues and known sensor strengths, followed by a new ambiguous hidden binary query. No hidden z or theta is included in neural inputs.
2. Train a **self-supervised prediction head** to estimate the *next observable cross-sensor correlation* (tanh(x_cal[i+1]*y_cal[i+1]/3)) from causal prefix tokens ending at i, and a query correlation head only when an optional probe is bought and observed. These targets are observational signals, **not supervised hidden polarity z**.
3. A stochastic Bernoulli probe decision is trained through an **on-policy REINFORCE score-function estimator** of actual net reward (correct final action minus incurred probe cost), using an EMA baseline and small entropy regularizer, **not analytic Bayes purchase targets**.
4. The final-action prediction head is trained with proper binary log loss, using the **action+binary correctness feedback** available after acting to reconstruct the correct binary outcome. The simulator privately computes correctness from theta, but theta is never passed directly to the optimizer. Distinguish this legitimate outcome supervision from fully unsupervised learning: it is **reward/outcome-supervised, latent-z-label-free**, not unsupervised training in every sense.
5. Decision-stage code never passes unpurchased y_probe into the policy. All models see identical causal histories, feedback and stochastic action/probe draws seeded independently of model initialization.

The SAME exact canonical **OriginalSIHybrid 64,614 parameters** vs **TransformerControl 64,637** from unchanged original `tam_research/si_original_hybrid_v0.py` Git blob `575c17dc2f39a29d930d82179aa0c96dcbdc7d0f`. ## Gate and interpretation fixed before confirmation
V9 ORIGINAL hybrid advancement to **further CPU research only** would require all:
- Normal-family hybrid realized reward >= Transformer by **0.015 absolute** across 3-seed means and wins at least 2/3 paired seeds;
- Hybrid beats **always-probe and never-probe** by >=0.025 normal reward, **without degenerate probe rate** (normal purchase between 0.1 and 0.9);
- Hybrid normal reward within **0.03** of known-model Bayesian reference; OOD reward >= Transformer on at least 2 of 3 OOD families; and measured hybrid training time <=1.5× Transformer.
A compact GRU beating both also counts against attributing success to hybrid complexity. A method that merely always buys and guesses correctly **fails** adaptive information-gathering despite its classification accuracy.
