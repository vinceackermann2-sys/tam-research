# Original screenshot-inspired SI / PCMA-v1 — known-family Bayesian probe economics falsifier

**2026-10-19 · DEVELOPMENT ONLY · CPU-only · Not an approved scientific experiment**

## Why this is a meaningful next step after PR #1520
The original paid-probe first-action randomized check (draft PR #1520, exact-head [CI run 39230601270](https://github.com/vinceackermann2-sys/tam-research/actions/runs/39230601270), 3,774 tests passed) produced **−0.446325 two-action net reward** relative to uniformly random guessing, with exploratory 24-world interval [−0.562093, −0.330557]. However the fixed second guess `guess=public symbol` **never inferred which cyclic rule permutation was active**. Theoretical prior expected difference −0.433333 was therefore almost predetermined. This result is a valid audit of sensor fee/opportunity cost, but cannot establish whether information buying can help a competent learner.

This branch builds a **cheap Bayesian history-aware controller** before proposing any additional SI hybrid compute. It uses the *same original* `OODRuleWorld`, paid probe action 3 (fee 0.1, no immediate reward, no context advancement, trusted public symbol on next action), three guess actions, hidden context persistent across sessions, and the existing factual public-only policy protocol.

## Explicit strong, NON-FAIR prior
The baseline's `CYCLIC_FAMILY` matches the three public source-level *candidate* permutations from the original DEVELOPMENT simulator. Its hypothesis family enumerates 3 possible rule indices × 3 hidden contexts × 2 ordinary-observation noise levels (0.12/0.50) × 2 shift/no-shift hypotheses = **36**, all initially uncertain. It also knows the hypothetical context transition (guess advances context +1, probe leaves context), possible one-time change at global clock 9, and that probes give a trusted public symbol. It does **not** know the actual selected world permutation/context/noise/scenario or receive hidden fields, `get_state`, simulator object, counterfactual reward, or outcome of an unchosen action. It updates beliefs only on the observed action's actual reward and next public observation, and assimilates the extra ordinary public sensor report on world restart.

**This structural information is substantially stronger than the unconstrained original neural model's prior.** It is an **informed, model-aware classical reference/upper-bound on task difficulty**, NOT a fair training-matched classical-vs-neural comparison. If it succeeds, that means a tiny classical known-family algorithm can achieve the behavior; it does not establish that any model can learn the family without being given it. If it fails, that is evidence the economics are unfavorable even with generous structural knowledge, not a universal impossibility theorem.

## Exact planned decision and alternatives
For each 2-action decision (even step budget at beginning), choose one action `a∈{guess0,guess1,guess2,probe3}` maximizing the Bayesian expected **real first reward minus actual fee, plus best attainable second guess reward after publicly observed first-action feedback**. This explicitly includes the value of guessing to *learn from reward* and any benefit of probing to get a trusted next observation; an all-guess control uses the exact same belief/training prior and planning horizon but denies `probe3`. At second/last action, the controller chooses the highest-posterior-success guess and never probes. The policy's actual reward totals are always from `run_ood_sessions` and `FactualTransition`, not hypothetical outcomes inside its planning routine.

A third benchmark, `SlidingWindowFactualControl(window=24, exploration=.10, probe_period=0)`, is a **model-free cheap factual no-probe** controller which has no rule-family prior. Thus the report compares *two matched-prior Bayes ablations* and an ordinary black-box statistical control, all taking an equal number of real actions in independently instantiated copies of each development world.

**Frozen single dev fixture:** `DEV_SEEDS = 501..524`, 6 worlds each stable/shift/noisy/long, **4 sessions/world**, 24/64 actions per world, **816 actual action opportunities per policy**; each policy receives equal budget. These IDs are only nonconfirmatory developer fixtures, not reserved/authorized independent scientific evaluation seeds. The environment's random-number consumption differs between policies because probes and guesses trigger different sensors; using the same initial world integer does **NOT** create a common-random-number paired potential-outcome experiment. Differences across world IDs are descriptive, not unbiased causal effects or statistical significance.

The reporting record contains three **actual paid-fee-adjusted** policy net returns per world, total chosen probes, the difference between allowing and disabling a probe with the **same explicit prior**, and a conspicuous denial of scientific claims. It does not calculate statistical significance, neural advantage, or protected heldout scores.
